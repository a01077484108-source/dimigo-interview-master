디미고 면접 마스터 웹앱 배포 안내

파일 구성
- index.html: 면접 준비 웹사이트
- manifest.json, sw.js, icon.svg: 홈 화면 설치 및 오프라인 캐시 지원

가장 쉬운 배포 방법(무료 옵션)
1. 이 ZIP의 압축을 풉니다.
2. Netlify Drop 또는 GitHub Pages에 index.html, manifest.json, sw.js, icon.svg 파일을 올립니다.
3. HTTPS로 제공되는 사이트 주소를 엽니다.
4. Android Chrome 메뉴에서 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.

주의
- HTML 파일만 휴대폰에서 직접 열면 PWA 설치/오프라인 캐시가 작동하지 않을 수 있습니다. HTTPS로 배포해야 합니다.
- 진도, 답안, 면접 대화, 일일 정리는 기본적으로 해당 브라우저의 localStorage에 저장됩니다. 브라우저 데이터 삭제, 다른 브라우저/기기 사용 시 기록이 없어질 수 있습니다. '백업·앱 설치' 탭에서 JSON 백업을 주기적으로 다운로드하고 복원하세요.
- 여러 기기 간 자동 동기화나 서버 계정 저장은 포함되어 있지 않습니다.
- 면접관 대화방 점수는 답변 길이와 일부 표현을 이용한 규칙 기반 참고 점수입니다. 실제 의미 분석형 AI 피드백을 제공하지 않으며, ChatGPT에서 받은 점수와 다를 수 있습니다.
