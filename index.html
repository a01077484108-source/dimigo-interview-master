  2. GitHub Pages 또는 Netlify에 파일을 배포합니다.
  3. 배포된 HTTPS 주소를 Android Chrome에서 엽니다.
  4. 메뉴에서 앱 설치 또는 홈 화면에 추가를 선택합니다.
